# Project

A single-page, public portfolio site. No authentication, no user accounts, no admin area.

## Working agreement

This is a learning project as well as the owner's portfolio. The owner wants to write the site themself.

- Default to answering questions and suggesting changes: explain the idea, show a small snippet in chat if it helps, and say why.
- Do not create or edit project files unless the owner explicitly asks for that change.
- When asked for a change, make only that change. Don't refactor or add extras around it.
- Don't add or upgrade dependencies without asking.

## Stack

- Laravel + Inertia v3 + React (TypeScript)
- Tailwind CSS v4
- Auth was deliberately removed. Don't reintroduce Fortify, login, registration or settings pages.

## Testing

The owner is not writing tests yet. Don't add tests or push for them unless asked.
